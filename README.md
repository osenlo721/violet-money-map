# Violet Money Map

Tengo un archivo CSV con datos de transacciones financieras. Las columnas son: Fecha, Descripción, Categoría (Alimentación / Transporte / Ocio / Salud / Vivienda / Otros), Tipo (Ingreso o Gasto), Monto. Aquí están los datos: [PEGA EL CONTENIDO DE TU CSV AQUÍ]. Crea un dashboard limpio y moderno que lea estos datos y muestre: 4 tarjetas de KPI en la parte superior — Ingresos Totales, Gastos Totales, Saldo Actual y Tasa de Ahorro %. Un gráfico de barras que compare Ingresos vs Gastos por mes. Un gráfico de dona que muestre el desglose de gastos por categoría. Una tabla que liste las 10 transacciones más recientes. Usa un tema oscuro con detalles en morado. Hazlo totalmente responsivo para que también funcione en celular.
